# v0.1.0 — Initial Multi-Workspace RAG Source Preview

Early **source-only pre-release** for development, experimentation and
operator-reviewed self-hosting. Not production-security certification; unrestricted
Internet exposure is not certified. No prebuilt Docker images are approved or
published. Only GitHub-generated source ZIP and tar.gz are release downloads.

## Included capabilities

- Headless authenticated API and CLI with workspace-scoped access controls.
- CPU-first ONNX embeddings and actual Qdrant vector indexing.
- Hybrid BM25/dense retrieval, reciprocal-rank fusion and deterministic reranking.
- Bounded TXT/PDF/DOCX ingestion and verifiable source/page/chunk citations.
- Durable SQLite jobs, idempotent retry, crash/outage recovery and backup/restore.

## Acceptance and known limitations

SPEC-001: **22 PASS / one FAIL / one BLOCKED**. RAG12 and RAG20 PASS.
**RAG15 BLOCKED:** real generative LLM answering has not been live-verified.
Generation is disabled by default; no provider availability, privacy, billing or
answer-quality certification follows from CPU retrieval tests.

**RAG21 FAIL:** actual image-security gates retain known OS vulnerabilities:

| Image | HIGH | CRITICAL |
| --- | --- | --- |
| Core API/worker | 44 | 0 |
| Qdrant | 43 | 0 |
| Optional UI | 44 | 0 |

Counts are scanner findings per image, not additive unique CVEs. Source jobs PASS;
image-security jobs FAIL with genuine nonzero exits. The complete workflow is not
green. Raw reports/SBOM/license evidence remain preserved; no suppressions, severity
changes or security-gate exceptions. Source publication does not approve image
distribution, deployment or production use.

Operators must review dependencies, OS packages, model/provider data policies,
credentials, network exposure and their environment. Limits include a single
SQLite writer/trusted host, English model with token truncation, text-only parsing
without OCR, and no validated GPU/distributed deployment or performance SLA.
